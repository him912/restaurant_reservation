# Restaurant Reservation Client

A React + Vite frontend for the restaurant reservation and review platform.

## Setup

1. Install dependencies:

```bash
cd client
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Update the API URL in `client/.env` if your backend is running locally or on a different host.

## Features

- Browse restaurants with search and filters
- View restaurant details, menu, and gallery
- Book reservations and check availability
- Read reviews and owner responses
- Register and login users

## Environment

The frontend reads the backend URL from `VITE_API_URL`.
